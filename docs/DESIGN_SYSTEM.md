# Omvana Retreat CMS

Design System

Version 1.0

---

# Purpose

This document defines the complete visual language of the project.

Every page, component, animation and interaction must follow these guidelines.

The objective is consistency.

No page should feel designed by a different person.

---

# Brand Personality

The interface should communicate:

• Calm

• Luxury

• Wellness

• Nature

• Simplicity

• Trust

• Premium Quality

It should never feel

❌ Corporate

❌ Flashy

❌ Colourful

❌ Busy

❌ AI Generated

❌ Template Based

---

# Design Inspiration

Primary References

• Omvana Retreat

• Aman Resorts

• Six Senses

• Apple

• Notion

• Airbnb (Content Layout)

• Linear (Dashboard Simplicity)

The goal is not to copy these websites.

Instead, borrow their design principles.

---

# Design Philosophy

Content is always more important than decoration.

Whitespace is a feature.

Typography creates hierarchy.

Photography tells the story.

Animations support the experience rather than attracting attention.

Every UI element should have a purpose.

# Typography Rules

Never use more than three font weights.

Avoid excessive bold text.

Increase whitespace before increasing font size.

Maintain generous line height.

Use sentence case.

Avoid ALL CAPS except labels.

# Icons

Outlined style.

24px default.

32px inside cards.

# Forms

Use React Hook Form.

Validation through Zod.

Inline validation messages.

Comfortable spacing.

Never place fields too close together.

---

# Navigation

Simple.

Minimal.

Readable.

Large click area.

# Animation Philosophy

Animations should feel calm.

They should never distract users.

Motion should support usability.

---

# Photography Style

Natural lighting.

Warm tones.

Real people.

Nature.

Yoga.

Retreats.

Minimal editing.

Large immersive imagery.

Avoid stock-photo appearance.

---

# UI Consistency Rules

Every new page should feel like it already existed.

Never invent new card styles.

Never invent new button styles.

Never invent new spacing.

Reuse existing components.

Consistency is more important than creativity.

---

# Final Principle

A visitor should feel relaxed within the first five seconds of opening the website.

The interface should disappear behind the content.

Every design decision should reinforce calmness, clarity and elegance.
